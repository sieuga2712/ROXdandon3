# Third-Party Components

This package contains no external runtime binaries (GDExtension), third-party GDScript libraries, or fonts. All code uses only built-in Godot 4 features (`Node2D`, `Sprite2D`, `AnimationPlayer`).

## Original Artwork

- Provider: Layer Lab (`2D Minimal-CharacterMaker`, Unity Asset Store)
- Included: 849 character, part, and thumbnail PNG files (`textures/`), the scene converted from the Unity `Character.prefab`, the `AnimationLibrary` converted from 16 AnimationClips, and 10 presets converted from `PresetData.asset`
- Rights status: See `licenses/ORIGINAL_ART_RIGHTS_REQUIRED.md` and `DISTRIBUTION_BLOCKED.md`

## Demo-Only Assets (Not Included in This Package)

The integrated demo (`demo/minimal/`) uses the Unity demo UI PNG files and the LINE Seed Sans font (OFL 1.1), but they are not part of this product archive.

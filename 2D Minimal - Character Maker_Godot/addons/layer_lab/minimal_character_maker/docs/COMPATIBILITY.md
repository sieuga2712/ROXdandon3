# Compatibility

- Verified engine: Godot 4.7.1 stable official (macOS editor; macOS universal and Windows x86_64 exports verified at runtime)
- Minimum engine: Godot 4.3 or later (uses `@export_storage`, static variables, and typed for loops). Versions 4.3 through 4.6 have not been verified.
- Renderers: Forward+, Mobile, and GL Compatibility (2D only)
- External dependencies: None (no GDExtension, EditorPlugin, or third-party font)
- Configuration schema: 1
- Source: Unity 2022.3 `2D Minimal-CharacterMaker` (PPU 100, AnimationClips at 60 fps)

Renaming the add-on directory breaks the catalog and scene paths.

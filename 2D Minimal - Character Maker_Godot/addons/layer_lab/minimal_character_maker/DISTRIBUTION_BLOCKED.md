# Distribution Hold

This package is a release candidate intended for local functional validation and packaging. External sale, sharing, and redistribution cannot be approved because the following evidence has not been confirmed:

1. The right to redistribute the Layer Lab original artwork included in this package (849 part and thumbnail PNG files) as a Godot add-on
2. Evidence that the distributing party is the original copyright holder or has explicit written permission from the copyright holder
3. The final end-user license agreement (EULA) for the original artwork and add-on code delivered to buyers

This product does not use Spine, so the Spine Editor and Spine Runtimes license terms do not apply. If the asset was obtained under the standard Unity Asset Store EULA, reselling the asset itself as a creation tool for another engine differs from shipping a finished game, so confirmation from the rights holder or a legal professional is required.

After the evidence and final terms are in place, remove this document, replace the release candidate suffix in `VERSION` with the final version, and run the distribution validation again.

Reference:

- https://unity.com/legal/as-terms
